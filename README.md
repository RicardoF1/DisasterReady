# Disaster Ready

Simulacion educativa 3D en primera persona sobre como reaccionar ante un sismo.
ODS 11 y ODS 13.

- Motor: Unity 6000.6.3f1 (todos deben usar esta version)
- Plantilla: Universal 3D (URP)
- Escenas: MainMenu, House

## Como abrir el proyecto
1. Instalar Unity 6000.6.3f1 desde Unity Hub.
2. Clonar el repositorio.
3. Unity Hub > Add > Add project from disk.
4. Esperar a que Unity genere la carpeta Library (tarda unos minutos).
