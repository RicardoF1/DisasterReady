# Disaster Ready - Core

## Descripción
Módulo principal encargado de controlar
el funcionamiento general del videojuego.

## Responsabilidades
- Controlar las fases del juego.
- Administrar temporizadores.
- Gestionar la salud del jugador.
- Administrar la puntuación.
- Calcular la calificación final.
- Gestionar eventos globales.
- Inicializar los sistemas mediante Bootstrap.

## Estados del juego
1. Menu
2. Preparation
3. Alarm
4. Earthquake
5. Evacuation
6. Result

## Integración
Los módulos Player, Level, UI y Audio
se comunican mediante interfaces y eventos
del namespace DisasterReady.
